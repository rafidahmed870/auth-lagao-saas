# Auth Lagao

A modern SaaS platform for managing software licenses for desktop applications, CLI tools, and other commercial software.

## Features

| Feature                                                                                | Description                                                        |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| ![License](https://img.shields.io/badge/License-Management-2563EB?style=flat-square)   | Generate and securely manage license keys.                         |
| ![Validation](https://img.shields.io/badge/Secure-Validation-16A34A?style=flat-square) | Backend-powered license validation with tamper protection.         |
| ![API](https://img.shields.io/badge/REST-Secure_API-DC2626?style=flat-square)          | Secure API for activation, verification, and license management.   |
| ![Device](https://img.shields.io/badge/Device-Lock-7C3AED?style=flat-square)           | Lock licenses to specific devices to prevent unauthorized usage.   |
| ![Expiry](https://img.shields.io/badge/License-Expiry-CA8A04?style=flat-square)        | Support for expiry-based and renewable licenses.                   |
| ![Dashboard](https://img.shields.io/badge/Cloud-Dashboard-0891B2?style=flat-square)    | Manage products, customers, and licenses from a unified dashboard. |
| ![SDK](https://img.shields.io/badge/Desktop_%26_CLI-Support-4F46E5?style=flat-square)  | Easy integration for desktop applications and CLI tools.           |
